Everything below is enforced by the checker, one finding per rule, each with what the handbook wants instead. This list is generated from the checker's source code, so it can never go stale — the readable version lives in RULES.md.

How it works

  1. Upload. Your .docx is read directly — styles, numbering, images, tracked changes.
  2. 89 checks run. Handbook rules, template rules, accessibility rules, submission hygiene. No AI guessing.
  3. You get locations + fixes. Every finding carries a stable rule ID and says what the handbook wants instead.

Want the auto-fixer too, or to run offline? The command-line tools are in the repo.

Not at Purdue?

Purdue is the only school supported today — every other university's rules are still waiting for someone who knows them (maybe you?). School requirements live in config files, not in code: adding yours means copying one JSON file and filling in your handbook's numbers.

Request your school — attach your graduate school's handbook (or its key numbers: page size, margins, font, spacing, heading styles) and the maintainer will help turn it into a config. Developers: the universities guide and the contribution guide walk you through it.
