# LinkedIn post 2 — open-source contributor call

Thesis ER is now open source, and I would love your help making it useful
beyond Purdue:

https://github.com/mogiiee/thesis-er

Why contribute?

- MIT licensed and Hacktoberfest-friendly
- `good first issue` starters that need no thesis-formatting knowledge
- Every checker rule includes a deterministic self-test proving it fires
- University-specific requirements live in JSON configuration files

The project currently runs 89 Purdue formatting, template, submission-hygiene,
and accessibility checks. It also includes an auto-fixer and a browser report:

https://mogiiee.github.io/thesis-er/

Useful contributions include another university's rule configuration, clearer
fix suggestions, sample fixtures, JSON reporting, and better chart-versus-photo
classification.

I built this because nobody should lose deadline time to margins, captions,
or inaccessible figures. Stars, issues, testing, and pull requests all help.

Unofficial community project. Not sponsored by, endorsed by, or affiliated
with Purdue University.
