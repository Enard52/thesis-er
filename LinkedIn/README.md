## Image guidance

Use the supplied site image as a **single-image post**, not as a link preview.
It shows the name, purpose, original 3D thesis object, 89-check count,
accessibility scope, and zero-storage promise without exposing thesis content.

Before posting, confirm that the live URL opens the same design and that a
test `.docx` produces a report. Do not upload a screenshot containing a real
thesis filename, findings, student information, or unpublished research.
