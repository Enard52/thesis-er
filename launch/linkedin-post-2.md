# LinkedIn post 2 — the open-source / Hacktoberfest call (publish ~1 week after post 1)

My Purdue thesis format checker is now open source, and I'd love your help making it better: https://github.com/mogiiee/thesis-er

Why contribute?
- MIT licensed, Hacktoberfest-friendly, with `good first issue` starters that need no thesis knowledge
- Every new rule ships with a self-test proving it fires — a great first PR if you've never contributed to open source
- Bigger ideas welcome too: the roadmap includes per-university rule configs (your school could be next), a JSON report flag for CI, and a smarter chart-vs-photo classifier

The backstory: I built this to survive Purdue's strict format review — 85 deterministic checks plus accessibility findings, with an auto-fixer and a browser version: https://mogiiee.github.io/thesis-er/. I don't want anyone else to nearly miss a deadline over margins and captions.

Unofficial community project, not sponsored by Purdue. Stars and PRs equally welcome.
